# Workshop App

This is a beginner's Expo Go app. Use the installed Expo SDK and compatible dependencies. Do not upgrade SDK or add native modules without explaining the impact on Expo Go.
Use React Native components, not HTML elements. Use AsyncStorage for local data. No backend, login, payment or AI API is needed.
Read the student's requirement and design files first. Explain your understanding before implementing a new feature. Change one feature at a time and verify existing behavior.
Run TypeScript, web behavior tests, and iOS export. A web test or exported bundle is not evidence of an iPhone device pass.
Keep credentials out of the app. Preserve existing data. Save a Git checkpoint before new features. Do not delete or reset student work to recover; make a separate recovery folder.
