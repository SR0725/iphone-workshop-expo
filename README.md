## 啟動
1. 在 Codex 打開這個資料夾，貼上講義裡的「環境準備提示詞」。
2. 雙擊 `啟動App.cmd`（Windows）或 `啟動App.command`（Mac）。第一次會請你在瀏覽器登入免費的 Expo 帳號。
3. iPhone 的 Expo Go 登入同一個 Expo 帳號，用 iPhone 相機掃 QR Code 開啟。
4. 手機一直連不上電腦時，改雙擊 `備用連線App`（透過 Expo 的公開通道，比較慢）。
